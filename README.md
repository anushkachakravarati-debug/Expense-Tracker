Expense Tracker

A Python-based Expense Tracker application that helps users record, view, search, and manage their daily expenses using file handling.

Features

- Add Expense: Record expenses with date, category, description, and amount.
- View Expenses: Display all recorded expenses.
- Search Expenses: Find expenses by category.
- Delete Expense: Remove an expense using its number.
- Show Total: Calculate the total expenses.
- File Handling: Save expenses to a text file and load them when the program starts.
- Persistent Storage: Keep expense records available between program sessions.

Technologies Used

- Python
- Object-Oriented Programming (OOP)
- File Handling
- Exception Handling

Concepts Practiced

- Classes and Objects
- Constructors ("__init__")
- Class Methods ("@classmethod")
- Lists and Loops
- Conditional Statements
- File Reading and Writing
- Basic Exception Handling

How to Run

1. Clone or download this repository.

2. Make sure Python is installed on your system.

3. Open the project folder in VS Code or Python IDLE.

4. Run the Python program:
   
   python expense_tracker.py

5. Follow the menu displayed in the terminal.

Data Storage

Expense records are stored in "expenses.txt" using a text-based format. The program loads saved records when it starts and updates the file when expenses are added or deleted.

Project Purpose

This project was developed to practise Python programming, object-oriented programming, and file handling by building a simple expense management application.
